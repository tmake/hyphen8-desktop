# Hyphen8 Desktop

Downloads of the Hyphen8 Desktop client. Only the newest version is kept here.

- macOS (Apple silicon and Intel): [Hyphen8-Desktop-macos.dmg](https://github.com/tmake/hyphen8-desktop/releases/latest/download/Hyphen8-Desktop-macos.dmg)
- Linux (x86_64): [AppImage](https://github.com/tmake/hyphen8-desktop/releases/latest/download/Hyphen8-Desktop-linux-x86_64.AppImage) · [.deb](https://github.com/tmake/hyphen8-desktop/releases/latest/download/Hyphen8-Desktop-linux-amd64.deb)

After you install it, pair it from the Desktop app in your Hyphen8 org.
